# Desarrollo web en entorno servidor 

Repositorio del módulo **Desarrollo web en entorno servidor**, perteneciente al ciclo formativo de grado superior de **Desarrollo de Aplicaciones Web (DAW)**.

En este repositorio se almacenarán los apuntes, ejercicios y prácticas realizados durante el curso.

## Tecnologías utilizadas

- PHP
- HTML5
- CSS3
- JavaScript
- MySQL
- Git y GitHub

## 📚 Contenidos

- Introducción al desarrollo web en servidor.
- Programación con PHP.
- Estructuras de control y funciones.
- Formularios y tratamiento de datos.
- Gestión de sesiones y cookies.
- Conexión con bases de datos.
- Desarrollo de aplicaciones web dinámicas.

Aprender a desarrollar aplicaciones web dinámicas mediante programación del lado del servidor, trabajando con PHP y bases de datos.
